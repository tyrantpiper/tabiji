# 📋 規格說明書：天氣卡牌經緯度隱藏與地點搜尋模組整合 (Spec)

> **文件狀態**: `APPROVED BY USER INTERVIEW`  
> **建立時間**: 2026-10-14  
> **關聯組件**: `WeatherPanel.tsx`, `LocationEditDialog.tsx`, `ActivityEditModal.tsx`  
> **設計規範**: iOS Inset Grouped, ActivityEditModal Parity, Tailwind CSS v4  

---

### 1. Problem Statement & Core Value (問題陳述與核心價值)

#### 1.1 使用者痛點 (User Problem)
1. **天氣卡牌視覺冗餘**: 天氣卡牌左上角顯示 `25.10, 121.55` 經緯度微標籤，佔用標題空間且對一般使用者無可讀性，破壞極簡 iOS 玻璃擬態質感。
2. **地點搜尋模組不一致與受限**: 點擊鉛筆進入「修改當日地點 (`LocationEditDialog`)」時，國家選單為寫死的 `<select>` 元素，無法手打輸入搜尋國家（如打「台灣」、「日本」），且版面為左 1/3 硬擠兩下拉、右 2/3 放搜尋框，排版狹窄破碎；反觀行程卡牌 (`ActivityEditModal`) 已支援雙欄篩選條、可手打/自選國家 datalist、動態地區選單與流暢搜尋。

#### 1.2 成功指標 (Success Metrics)
- **天氣卡牌頂部簡約化**: 天氣卡牌左上角移除經緯度數值，保留 `📍 [地點名稱] ✏️`。
- **搜尋體驗 100% 對齊**: `LocationEditDialog` 採用與 `ActivityEditModal` 完全一致的雙層佈局（第一層：國家可手打/自選 + 地區連動；第二層：地點名稱輸入 + 搜尋按鈕）。
- **保留診斷能力**: 對話框內的「📍 目前地點」與「⚡ 自動同步」保留經緯度參考，避免破壞確認功能。
- **零降級**: `tsc --noEmit` 0 錯誤、`npm run lint` 0 錯誤、前端與後端測試 100% 綠燈。

### 2. UI Layout & Architecture (介面佈局與架構)

#### 2.1 WeatherPanel 頂部地點欄位
- **Before**: `[📍 MapPin] [地點名稱] [25.10, 121.55 (微標籤)] [✏️ Edit3]`
- **After**: `[📍 MapPin] [地點名稱] [✏️ Edit3]`

#### 2.2 LocationEditDialog 搜尋模組 (與 ActivityEditModal 一致)
```
┌─────────────────────────────────────────────────────────────┐
│ 📍 目前地點: 故宮博物院 (25.1024, 121.5485)                   │
├─────────────────────────────────────────────────────────────┤
│ ⚡ 自動同步: 故宮博物院 (25.1024, 121.5485)                   │
├─────────────────────────────────────────────────────────────┤
│ 🔍 搜尋地點                                                 │
│ ┌───────────────────────────┬─────────────────────────────┐ │
│ │ 🌍 國家 (可手打或自選)       │ 🏙️ 地區 (全部/可選)         │ │
│ └───────────────────────────┴─────────────────────────────┘ │
│ ┌──────────────────────────────────────────────┬──────────┐ │
│ │ 輸入商家或景點名稱...                        │  [🔍]    │ │
│ └──────────────────────────────────────────────┴──────────┘ │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 搜尋結果清單 (展示類型圖標、地名、詳細地址、經緯度)     │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 3. Implementation Steps (實作步驟)

1. **`WeatherPanel.tsx`**: 移除 `resolvedLocation && (<span ...>{resolvedLocation.lat.toFixed(2)}, ...</span>)`。
2. **`LocationEditDialog.tsx`**:
   - 替換寫死 `<select>` 為 `<Input list="loc-edit-country-options" ... />` 搭配 `<datalist>`，支援手打與自選，涵蓋日、台、韓、泰等常用國。
   - 地區欄位與 `searchCountry` 聯動：若在 `COUNTRY_REGIONS` 則渲染 `<select>`，否則渲染 `<Input placeholder="🏙️ 地區 (可選)" />`。
   - 排版改為雙欄第一層（國家+地區）與第二層全寬搜尋輸入框。
3. **驗證與測試**: 執行型別檢查、ESLint 與 Vitest 單元測試。
