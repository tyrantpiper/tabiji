## 核心結論：全球通用適配到底「有沒有搞頭」？

### 結論：若按傳統思維做「必死無疑（夜郎自大）」，但按「確定性規則矩陣引擎」做則是「真正的全球降維打擊（獨步業界）」！

1. **為什麼做「純匯率換算或單一公式」必死無疑？**
   - 99% 的開發者自以為「全球退稅 = 金額 × 當地稅率%」。
   - **這是嚴重的致命錯誤！**
     - 歐洲退稅絕非退回全額 20% VAT！Global Blue 與 Planet 等私營代辦商會抽成 20%~35% 手續費，且收取每單 1~3 歐元手續費，實退率僅約 11%~14%。
     - 若遊客在退稅單勾選退回「母國貨幣（如 TWD/USD）」，代辦商會觸發 **DCC (動態貨幣轉換)**，以高於市價 5%~15% 的掠奪性匯率結算，退稅直接被吃掉大半！
     - **英國自脫歐後已全面廢止外國遊客退稅**；**美國各州銷售稅為地方稅，聯邦與絕大多數州根本不提供遊客退稅**；加拿大亦已廢除遊客退稅。若 App 對這些國家顯示「可退稅」，會直接淪為國際笑柄！
     - **日本將於 2026 年 11 月 1 日起全面廢除「店內當場現折免稅」**，改為先支付含稅價、出境機場海關過機後才退款；取消消耗品 50 萬日圓上限與封條限制。
     - **韓國自 2026 年 1 月 1 日起全面廢止外國人醫美手術退稅方案**；一般商品維持 15,000 韓元門檻。

2. **為什麼 Tabiji 做「全球退稅 ✕ 匯率 ✕ 信用卡回饋精算矩陣」有巨大搞頭？**
   - 市面上**完全沒有任何一個 App** 能夠做到：
     - **自動判斷該國是否有觀光退稅**（若選美國/英國，立刻精準標註「該國無觀光客退稅機制，切勿相信退稅代辦」）。
     - **含稅/未稅雙向精確推導**：含稅價取除數 `P / (1 + r)`，未稅價取乘數 `P × (1 + r)`，杜絕市面計算機的百分比除數膨脹 Bug。
     - **代辦商淨額扣除與 DCC 防坑告警**：自動顯示「預估實退金額」與「強烈警告：退款請務必選當地貨幣，切勿選本國貨幣！」。
     - **聯動個人信用卡庫**：自動計算 `(未稅價或扣稅後金額) × 銀行匯率 × (1 + 1.5% 海外手續費 - 卡片回饋率%)`，即時給出「真正台幣帳單扣款金額」與「最划算卡片推薦」！

## 第二章：網路大神爭議點與血淚避坑指南 (Reddit / V2EX / FlyerTalk 實測)

### 2.1 代辦商掠奪性收費（The Global Blue / Planet Extraction Machine）
1. **DCC 貨幣轉換陷阱 (The DCC Exchange Rate Robbery)**：
   - 當旅客在機場退稅機台或表單上選擇「退至信用卡」，機台會以極具誘導性的介面詢問：「是否直接退回您的本國貨幣（如新台幣 TWD、美金 USD）？」
   - **實測真相**：若選擇退本國貨幣，代辦商使用自家離譜的「賣出匯率」，外加 3%~5% 的貨幣轉換費，導致最終到手金額比預期少 8%~15%！
   - **大神鐵律**：**一律勾選退回「消費地當地貨幣（EUR / JPY / KRW）」**，交由發卡銀行以國際組織牌告匯率清算，能拿回最多錢。
2. **階梯式手續費剝削 (Sliding Scale Fee Table)**：
   - 代辦商不是按固定趴數收費，而是採用級距表。小額消費（如剛過 €100 門檻），手續費可能高達稅額的 40%~50%；高額精品（如 €3,000 以上），實退率才會接近 14%~15%。
3. **現金退稅的「雙重暗扣」**：
   - 在機場退稅櫃檯領取現金，每張退稅單會被強制徵收 €3 到 €5 的「現金服務費 (Cash Handling Fee)」；若是退非歐元現金，還會被二度收取匯差。

## 第四章：Tabiji 全球精算矩陣引擎設計規格 (Global Actuary Engine Spec)

### 4.1 核心數據結構定義
```typescript
export interface CountryTaxRule {
  countryCode: string;          // ISO 2-letter (e.g. 'JP', 'FR', 'IT', 'US', 'GB')
  countryName: Record<string, string>; // i18n
  currency: string;             // 'JPY', 'EUR', 'USD', 'GBP', 'KRW', etc.
  vatRate: number;              // 標準稅率 (e.g. 0.10, 0.20, 0.22)
  reducedVatRate?: number;      // 優惠稅率 (食品/書籍等)
  minSpendThreshold: number;    // 免稅門檻 (本國幣)
  isThresholdTaxInclusive: boolean; // 門檻是看含稅還是未稅
  refundMode: 'in_store' | 'intermediary_airport' | 'direct_customs' | 'none';
  agencyFeeRatio: number;       // 代辦商抽成率 (e.g. 0.30)
  hasTaxFree: boolean;          // 是否有觀光退稅
  warningNotes?: string;        // 陷阱提示 (如 UK 廢除、US 無退稅、DCC 警告)
  effectiveFrom?: string;       // 政策生效日期 (如 JP 2026-11-01)
}
```

                       │
                       ▼
      [精確反推未稅淨額 BaseAmount 與稅金 TaxAmount]
        ├── 含稅: Base = P / (1 + r), Tax = P - Base
        └── 未稅: Base = P, Tax = P * r
                       │
                       ▼
      [門檻判斷 (Threshold Validator)]
        ├── 未達門檻: 提示「差額多少可退稅，可省下約 XX 台幣」

                       │
                       ▼
      [代辦商手續費與實退預估 (Net Refund Estimator)]

                       │
                       ▼
      [個人信用卡庫海外淨支出精算 (Card Actuary)]
        ├── 刷卡折合台幣: (P - NetRefund) * Rate * (1 + 1.5% - RewardRate%)
